# PS-RX - plugin Decky

Pannello nel menu rapido di Steam (SteamOS) per il ricevitore PS-RX, tutto via USB:

- **Gamepad:** controller collegati (batteria, segnale, frequenza), abbinamento, impostazioni per controller.
- **Rete:** WiFi del ricevitore, reti salvate (fino a 5), PC da svegliare con il Wake-on-LAN.
- **Sistema:** impostazioni del ricevitore, aggiornamento del firmware, registro.

Notifiche di Steam quando un controller si collega (posto, modello, modalità, batteria) e quando la
batteria si sta scaricando.

Installazione: Decky Loader → Impostazioni → Modalità sviluppatore → "Installa plugin da ZIP".
